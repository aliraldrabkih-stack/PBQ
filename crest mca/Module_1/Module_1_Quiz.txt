    (B) The point where data moves from a less trusted context into a more trusted one
    (C) The API rate limit imposed on the application
    (D) The physical server hosting the model

    (B) Tool, plugin, and agent invocation
    (C) Physical theft of a server rack
    (D) Weak Wi-Fi encryption on an office network
